WEB ULTAH PACAR — 15 NOVEMBER

Cara pakai:
1. Buka index.html.
2. Kalau mau musik, masukkan file lagu MP3 ke folder yang sama dengan index.html.
3. Rename file lagu menjadi: music.mp3
4. Buka ulang index.html.
5. Klik amplop untuk membuka surprise.

Catatan:
Browser biasanya memblokir autoplay. Karena itu musik dimulai setelah amplop diklik.
